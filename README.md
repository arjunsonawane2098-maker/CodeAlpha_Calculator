# CodeAlpha Calculator

A responsive calculator web application developed as part of my CodeAlpha Frontend Development Internship.

## Features
- Addition, Subtraction, Multiplication and Division
- Clear and Delete functionality
- Decimal calculations
- Keyboard support
- Responsive user interface
- Error handling

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Structure
- index.html
- style.css
- script.js

## How to Run
1. Clone or download this repository.
2. Open the project folder.
3. Open index.html in your browser.
4. Start calculating!
